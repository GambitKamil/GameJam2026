# Правила для ИИ-агентов (Codex, Claude Code и др.)

Unity-игра для геймджема, 3 человека, ~41 час. Unity **6000.3.29f1**, Built-in RP, сборка **WebGL**. Роли и план — в `README.md`.

## Прежде чем что-то менять

- Узнай у человека его роль: **Дизайн и UI**, **Геймплей** или **Системы**. Меняй только папки этой роли (таблица в `README.md`). Нужно изменить чужое — скажи человеку, а не правь сам.
- Всё наше — в `Assets/_Game/`. Не трогай `ProjectSettings/`, `Packages/` и `Scenes/Main.unity` без явной просьбы.

## Unity

- Не создавай, не переименовывай и не удаляй ассеты в обход Unity (у каждого ассета есть `.meta` с GUID, на нём держатся все ссылки). Новые `.cs` можно создавать файлом — Unity сам сделает `.meta`. После этого проверь консоль на ошибки компиляции.
- Не правь `.unity` и `.prefab` как текст, если можно сделать это через редактор (MCP for Unity) или скриптом.
- Пиши код для **WebGL**: никаких потоков (`System.Threading`), файловой системы и нативных плагинов.
- Связь между ролями — через публичные методы и события (`GameManager`, `AudioManager`), а не через поиск объектов по имени.
- Простота важнее архитектуры: это джем, а не продукт.

## Git

- Работай в ветке своей роли (`design/…`, `gameplay/…`, `systems/…`), не коммить в `main` напрямую.
- Коммить файл вместе с его `.meta`. Не коммить `Library/`, `Temp/`, `Logs/`, `UserSettings/`, сборки.
- Файлы больше 50 МБ — не в репозиторий.
