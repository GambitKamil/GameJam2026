## 1. Подключение (один раз)

1. Если рядом нет репозитория — `git clone https://github.com/GambitKamil/GameJam2026.git` (не в iCloud/OneDrive/Dropbox) и перейди в папку `GameJam2026`. Если уже есть — `git pull`.
2. Выполни `docs/ONBOARDING.md` от начала до конца. Роль для шага 8: `systems`. На macOS модуль **Windows Build Support (Mono)** для тебя обязателен.
3. Прочитай `AGENTS.md` (условия джема, общие правила, синхронизация) и `README.md` (роли и план). Работай по ним всегда.

## 2. Твоя зона

Меняешь **только** это (и `.meta` этих файлов):

- `Assets/_Game/Scripts/Core/` — GameManager, AudioManager, переходы сцен, диалоги/тексты, сохранения, отладка
- `Assets/_Game/Audio/` — музыка и звуки
- `Assets/_Game/Scenes/Main.unity` — стартовая сцена: меню и менеджеры
- **общие настройки**: `ProjectSettings/` (теги, слои, Build Settings, Player Settings), `Packages/` (пакеты), `.gitignore`. Остальные просят тебя, ты меняешь и пушишь.
- раздел «Договорённости» в `README.md`
- своя песочница `Assets/_Game/Scenes/Sandbox/<Name>.unity`

## 3. Что делает роль

- **Цикл игры**: Menu → Playing → Paused → Win / Lose → Restart / Next level → Credits. `GameManager` с публичными методами и событиями для других ролей.
- **Переходы сцен**: `Main.unity` загружает уровни из `Scenes/Levels/` по порядку. Следи за списком сцен в Build Settings.
- **Тексты и диалоги**: простая система показа реплик истории (`ShowLine("...")`, очередь реплик, пропуск по клавише). Тексты пишет Геймплей, вид окна — Дизайн.
- **Очки и прогресс**: счёт, лучший результат (`PlayerPrefs`).
- **Звук**: `AudioManager` (музыка + эффекты по имени: `Play("jump")`), громкость музыки и эффектов, mute, запоминание в `PlayerPrefs`. Подбор музыки и звуков — и сразу запись в `CREDITS.md`.
- **Для жюри** (показ 5 минут): рестарт и пропуск уровня горячими клавишами (например `R` — заново, `N` — следующий), выход `Esc`, громкость доступна сразу. Игра начинается за пару секунд, без длинных загрузок.
- **Сборка под Windows** (обязательна): File → Build Profiles → **Windows**, Architecture **x86_64**. Первая — к 6-му часу, дальше каждые ~4 часа. На macOS собирается через модуль Mono — запуск на Windows проверить на ноутбуке с Windows (у кого-то из команды или ментора). Не проверенный на Windows запуск — сказать человеку прямо.
  - Product Name и Company Name в Player Settings; окно 1920×1080 (Fullscreen Window), чтобы `Esc`/`Alt+F4` работали.
  - Сборка → **zip всей папки** (`.exe`, `_Data`, `UnityPlayer.dll`, `MonoBleedingEdge`). Проверить: **распаковать архив в новое место и запустить оттуда**.
  - Браузерная версия (WebGL) — по желанию, только если Windows-сборка уже готова.
- **Производительность** (10 баллов): стабильные 60 FPS на обычном ноутбуке, без рывков при загрузке уровней; смотреть Profiler, следить за размерами текстур и звуков (музыка — Streaming/Vorbis), размер архива разумный.
- **Сдача**: страница игры на itch.io — загрузить zip заранее (сеть общая), проверить скачанный архив, описание, управление, титры; копия сборки на Google Drive. **Публикуешь и отправляешь — только по явному решению команды.**
- **Титры**: из `CREDITS.md` — экран Credits в игре и раздел на странице itch.io.
- **Страж `main`**: после каждого `git pull` консоль без ошибок. Если `main` сломался — сразу сказать, чей коммит (`git log`), и попросить починить или откатить (`git revert`).

## 4. Стыки с другими ролями

- **С Дизайном.** Его UI-префабы вызывают твои методы (`StartGame()`, `Restart()`, `TogglePause()`, `SetMusicVolume(float)`…) и слушают твои события (`ScoreChanged`, `StateChanged`…). Ты ставишь его префабы в `Main.unity` и в уровни (по договорённости с Геймплеем).
- **С Геймплеем.** Он зовёт `Win()`, `Lose()`, `AddScore(n)`, `AudioManager.Play("…")`, `ShowLine("…")` и объявляет события (`Jumped`, `Died`…) — на них ты вешаешь звуки, не трогая его код.
- **Договор об именах.** В первые 2 часа запиши в `README.md` → «Договорённости» названия методов, событий и звуков. Это общий словарь команды.
- **Общие настройки.** Кто-то просит тег, слой, пакет или сцену в Build Settings — ты делаешь, пушишь и говоришь всем сделать `git pull`.
