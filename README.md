# GameJam2026

Проект команды на 41 PlayLab Game Jam '26. Unity **6000.3.29f1**, Built-in Render Pipeline, цель сборки — **WebGL** (itch.io).

## Как начать (каждому)

1. Установить Unity **6000.3.29f1** с модулем **Web Build Support**. Другая версия, даже соседняя, перепишет файлы проекта и даст конфликты.
2. Склонировать репозиторий: `git clone https://github.com/GambitKamil/GameJam2026.git`
3. Открыть папку в Unity Hub через **Add → Add project from disk**. Первое открытие долгое: Unity строит `Library/`.
4. Создать себе песочницу: `Assets/_Game/Scenes/Sandbox/<ТвоёИмя>.unity`. Пробовать что угодно — там.

## Роли

| Кто | Роль | Отвечает за | Его папки |
|---|---|---|---|
| **Али** | Дизайн и UI | Арт-стиль и палитра, спрайты/модели, все экраны UI (меню, HUD, пауза, победа/проигрыш) — вёрстка и анимация, VFX и «сочность» (частицы, тряска, твины), анимации персонажей, видео геймплея 2–3 мин, обложка и скриншоты для itch.io | `Art/` `UI/` `VFX/` `Animations/` `Prefabs/UI/` `Scripts/UI/` |
| **Друг 1** | Геймплей | Главная механика, управление игроком, объекты/враги/препятствия, уровни и их сложность, камера и физика, ощущение управления | `Scripts/Gameplay/` `Prefabs/Gameplay/` |
| **Друг 2** | Системы, звук, сборка | Игровой цикл (меню → игра → победа/проигрыш → рестарт), GameManager, счёт и прогресс, переходы сцен, звук (AudioManager, подбор музыки и SFX), настройки громкости, **пропуск уровня для жюри**, WebGL-сборки, загрузка на itch.io + копия на Drive, слияние веток в `main` | `Scripts/Core/` `Audio/` `Scenes/Main.unity` |

Друг 2 — **интегратор**: он сливает ветки в `main` и единственный, кто правит `Main.unity`. Остальные приносят свою работу префабами.

### Где роли стыкуются

- **UI ↔ Системы.** Системы дают методы и события (`GameManager.StartGame()`, `Restart()`, событие `ScoreChanged` и т.п.), UI их вызывает и на них подписывается. Сначала договорились о названиях, потом каждый пишет свою сторону.
- **Арт ↔ Геймплей.** Геймплей сразу делает рабочие префабы с заглушками (кубы, квадраты). Дизайн потом меняет внутри префаба только картинку/модель, не трогая скрипты и коллайдеры.
- **Звук ↔ Геймплей.** Геймплей вызывает `AudioManager.Play("jump")`, Системы решают, какой звук играет.

## Правила Git

- **`main` всегда запускается.** Сломанное в `main` не кладём.
- Работаем в ветках: `design/…`, `gameplay/…`, `systems/…`. Ветка живёт 1–3 часа, потом Pull Request в `main`.
- Перед работой — `git pull`. Коммиты маленькие и частые.
- Файл и его `.meta` всегда коммитятся **вместе**. Переименовывать и перемещать ассеты — **только внутри Unity**, не в Finder/Проводнике (иначе ломаются ссылки).
- **Одну сцену или префаб двое одновременно не правят** — Unity-сцены плохо сливаются. Своя песочница + свои префабы.
- Не кладём в репозиторий файлы больше 50 МБ (у GitHub жёсткий лимит 100 МБ). Исходники (`.psd`, `.aep`, `.blend`, исходные `.wav`) — на общий Drive, в Unity — только экспорт (`.png`, `.ogg`, `.fbx`).
- `ProjectSettings/` и `Packages/` меняем только договорившись.

Все работают с ИИ (Codex, Claude). Правила для агентов — в [`AGENTS.md`](AGENTS.md), его читают и Codex, и Claude Code (через `CLAUDE.md`). Указывай агенту свою роль, чтобы он не лез в чужие папки.

В проекте установлен пакет **MCP for Unity** (Window → MCP for Unity): агент может сам управлять редактором. Подключать необязательно.
