# GameJam2026

Игра нашей команды на **41 PlayLab Game Jam '26**. Тема — **Kontrol etmek**.

- Unity **6000.3.29f1**, Built-in Render Pipeline, uGUI + TextMeshPro.
- Сдача — через itch.io **до 12:00, 29 ноября 2026 (UTC+3)**. Обязательна **сборка под Windows**, браузерная — по желанию.
- **Игра полностью на английском.** Всё, что видит игрок, и всё внутри `Assets/`. С ИИ-агентами общаемся по-русски.

## Как подключиться

Открой свой ИИ-агент (Codex, Claude Code) в папке, где будет лежать проект, и отправь ему **целиком** файл своей роли:

| Кто | Файл |
|---|---|
| Али — Дизайн и UI | [`docs/roles/design-ui.md`](docs/roles/design-ui.md) |
| Камиль — Геймплей, уровни и сюжет | [`docs/roles/gameplay.md`](docs/roles/gameplay.md) |
| Шукри — Системы, звук и сборка | [`docs/roles/systems.md`](docs/roles/systems.md) |

Агент сам склонирует проект, проверит версию Unity, вход в GitHub и доступ на запись, настроит git и сделает пробный push. Что нужно сделать руками — скажет. Порядок для агента — [`docs/ONBOARDING.md`](docs/ONBOARDING.md), общие правила — [`AGENTS.md`](AGENTS.md).

## Синхронизация

Все работаем в ветке **`main`**, каждый — только в своей зоне. Подробно — в `AGENTS.md`, агенты делают это сами. Коротко:

- **Сел работать** → сохранил всё в Unity → `git pull`.
- **Кусок готов** (консоль без ошибок, Play запускается) → коммит своих файлов → `git pull` → `git push` → написал в чат команды «запушил: …».
- **Увидел «запушил» в чате** → сохранил в Unity → `git pull`.
- Одну сцену или префаб двое одновременно не правят. Пробы — в своей песочнице `Scenes/Sandbox/<Name>.unity`.
- Ассеты переименовываем и перемещаем **только в Unity**, не в Finder/Проводнике.
- `ProjectSettings/`, `Packages/`, `Scenes/Main.unity` меняют только Системы — остальные просят.
